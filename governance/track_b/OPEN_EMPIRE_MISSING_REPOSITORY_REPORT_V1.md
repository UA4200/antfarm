## Missing Repository 1: `trading-system`

### Justification

The trading module at `~/.openclaw/trading/` is the most operationally critical unversioned system in the stack. It:

- **Executes real trades** on Kalshi ($25.19 capital deployed) and Polymarket US ($40 capital deployed) — $65.19 total live capital
- **Processes automated decisions** every 5 minutes via 3 PM2 agents (cashclaw_director, cashclaw_arb, polymarket_trader)
- **Enforces daily spend caps** ($10 each) against a JSON log file
- **Has NO git repository** — confirmed by discovery scan

The absence of a git repository means:
- No rollback capability if a bug is deployed to trading logic
- No audit trail of changes to signal engine, executor, or kelly criterion parameters
- No ability to review history of spend cap or risk parameter changes
- No CI/CD safety net before deploying changes to live trading code
- Impossible to reproduce a past state if needed for regulatory or audit purposes

### Operational Evidence

```

- cashclaw_director (PM2 ID 38) — trading.agents.director.run
- cashclaw_arb      (PM2 ID 39) — trading.agents.arb.run
- polymarket-trader (PM2 ID 40) — trading.agents.polymarket_trader.run
- trading_sentinel  (PM2 ID 41) — trading.agents.sentinel.run

Key modules:
- trading/clients/kalshi_client.py     (RSA-PSS V2 auth)
- trading/clients/polymarket_client.py (Ed25519 auth)
- trading/shared/{signals,kelly,risk,logging}.py
- trading/agents/{director,arb,polymarket_trader,sentinel}/run.py
```

## Missing Repository 4: `secrets-governance`

### Justification

`~/.openclaw/secrets/.env` contains **40 production keys**. These include:
- API keys for Kalshi, Polymarket, Telegram, Discord, Anthropic, OpenAI
- RSA private key references (Kalshi V2 auth)
- Database credentials (PostgreSQL 18.3, port 5432)
- n8n webhook credentials

There is no:
- Key inventory / manifest under version control
- Key rotation policy
- Key expiry tracking
- Secret governance policy document
- Access control documentation

Note: The `.env` file itself should **never** be committed to git. What SHOULD be versioned is:
- A key manifest (names only, no values)
- Rotation policy and procedure
- Access control matrix
- Template `.env.example` for bootstrap
